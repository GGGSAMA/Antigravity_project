# 宗门势力架构设计 V1 (Faction System V1)

> **设计核心逻辑链条**：
> 大地图柏林噪音 (灵脉/资源) ➔ 宗门选址与定级 (强弱权重) ➔ NPC 生成配额 (数量/境界比例)

## 1. 灵气与资源底座 (World Resource Base)
在大地图生成（柏林噪音）时，计算并划分出【灵脉节点】。
- **灵脉品阶**：一阶到九阶（对应灵气的浓郁程度）。
- **资源类型**：如火脉（适合炼器/火系宗门）、木脉（适合炼丹/木系宗门）。
- 宗门的建立必须依托于灵脉，灵脉的品阶直接锁死了该宗门的**“实力上限权重”**。

## 2. 宗门核心属性表 (Faction Data Structure)
每个随机生成的宗门，将在底层数据库拥有以下核心属性：

| 属性名称 | 说明 | 决定因素 |
| :--- | :--- | :--- |
| **宗门名称** | 自动生成的修仙门派名（如：青云谷、血魔宗） | 随机算法 / 势力属性词缀 |
| **势力倾向** | 正道、魔道、中立商会、隐世妖族 | 随机权重 |
| **主修功法系** | 剑修、法修、体修、符箓、炼丹 | 占据的灵脉/资源种类 |
| **灵脉底蕴权重** | 决定宗门灵气储备 (0-100) | 地图生成的灵脉品阶 |
| **综合繁荣度** | 决定能养活多少弟子 (人口上限) | 灵脉底蕴 + 占据的资源点 |

## 3. 从宗门推导 NPC 生成 (Demographic Generator)
当确定了某宗门的“综合繁荣度”和“灵脉底蕴”后，NPC 生成器脚本（您提到的类似《觅长生》的机制）就会开始工作：

* **总人数分配**：繁荣度 90 的顶级大派可能生成 500 个挂名 NPC，而繁荣度 10 的落魄宗门只有 20 个人。
* **境界比例金字塔**：
  - 顶级大派：元婴期(2%)，金丹期(10%)，筑基期(30%)，练气期(58%)。
  - 落魄小派：可能掌门也就是个筑基巅峰，其余全练气。
* **男女比例与性格倾向**：例如纯阴体质的合欢宗设定为女90% 男10%，而狂霸的血魔宗可能嗜血性格极多。

## 4. 演化周期 (The Simulation Loop)
宗门不仅是死的数据，还会随着时间演化：
1. **宗门战争**：互相抢夺地图上的灵脉节点。
2. **气运衰落**：资源枯竭导致高境界 NPC 离开或寿元耗尽无法突破，宗门繁荣度下降，下一年生成的新鲜血液（低阶弟子）减少。
