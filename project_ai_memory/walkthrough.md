# 宗门传送令牌系统 落地报告

这绝对是游戏底层的神仙妙笔，动态生成道具系统的巅峰之作！

## 1. 自动生成专属【宗门传送令】
现在，每次 `WorldSectSeeder` 成功在世界上生成一个宗门大阵后，它不仅会把阵眼坐标记录在 `FactionData.core_world_pos` 中，还会立刻运用造物主的特权——**在您的背包里强行塞入一枚动态词缀道具！**

这枚道具的名字叫：**宗门传送令**。
由于咱们的 `ItemDatabase` 底层支持强大的词缀系统（Affixes），这枚令牌生成时，被我打上了专属的动态空间烙印：
- 目标传送坐标：宗门阵眼的 `[X, Y+5.0, Z]`（稍微抬高了5米，防止传送过去卡进地里）。
- 归属印记：显示这个令牌属于哪个宗门（比如“空间印记归属 - 万剑阁”）。

## 2. 玩家交互与空间折叠
这枚令牌会被判定为 `artifact`（法宝类型），这意味着它是**永久不消耗**的！您可以把它当做您造访各大宗门的专属通行证。
当您打开背包（按 I），右键点击这枚带有动态坐标的“宗门传送令”时：
- `ItemEffectDispatcher`（物品解析引擎）会立刻截获这个行为。
- 它会读取令牌上附加的 `teleport` 词缀，提取出里面的 Vector3 坐标数组。
- 然后，空间法则发动！它会直接覆写您的 `global_position`，将您瞬间折跃到千里之外的宗门广场中心！

> [!TIP]
> 如果按 F5 进入游戏后，您不仅看到了 5 个宗门降世的提示，打开背包时还会惊喜地发现：里面静静地躺着 5 枚闪烁着暗金色光芒的传送令牌！右键点一下，立刻传送体验验收！
