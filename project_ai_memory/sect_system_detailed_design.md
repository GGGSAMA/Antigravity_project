# 宗门系统与宏观生态引擎详细设计 (Sect Ecosystem & Macro AI)

**文档状态**: 草案 (Draft) / **核心理念**: “倾尽全宗资源，培养并留住绝世高手”

---

## 1. 宗门核心：宏观大脑架构 (SectBrainAI)
有别于传统的格子建造系统，本游戏中的宗门是一个基于“利益分配”与“自我延续”的抽象生命体。

### 1.1 大脑的核心驱动函数
宗门大脑并不做微观寻路，它的所有决策均围绕**四维宗门欲望 (Sect Needs)** 展开：
- **资源储备 (Resources)**：维系阵法、发放俸禄、炼制丹药的刚需。
- **宗门威望 (Prestige)**：影响招收新弟子的质量与速度。
- **领地掌控 (Territory)**：领地越大，能圈占的灵脉节点和野外产出点越多。
- **防御底蕴 (Defense)**：护宗大阵的强度及高端战力（长老数量）存活率。

### 1.2 自上而下的任务派发池 (Task Pool)
当宗门某项需求极低时，大脑会自动发布【宗门悬赏任务】进入 `SectTaskBoard`（宗门任务悬赏榜）。
**任务流转的具体细节 (怎么派任务)**：
1. **生成环节**：宗门炼丹长老的 AI 判定“极品凝气丹库存不足”，随即向大脑提交申请。大脑将此申请转化为具体悬赏：“需要 50 株赤血草，单株奖励 10 功勋”。
2. **揭榜环节**：处在闲置状态（Idle）且无固定驻守任务的底层弟子，会定时访问 `SectTaskBoard`。AI 根据弟子的境界（如炼气期）和当前位置，认领最适合自己的任务。
3. **互斥锁**：一旦任务被接取，该需求指标被锁定，防止全宗 100 号人同时跑去采同一株草。

## 2. 阶级跨越：功勋与官位闭环 (Meritocracy Loop)
这是宗门内生态永动机的核心。没有单纯的数值暴涨，一切全靠底层互卷。

### 2.1 任务执行与物资上缴 (怎么拿东西)
- **获取物资**：弟子接取任务后，利用 `WorldGridManager` 寻找符合条件的最近资源点（如森林区）。到达后播放采集动画，并在其私有 `Inventory` 中生成对应的【赤血草】物品。
- **上缴结算**：弟子必须**活着走回宗门大阵**，前往【宗门宝库（Treasury Node）】。此时触发上缴逻辑：
  1. 扣除弟子背包中的草药。
  2. 增加宗门的全球库存储备。
  3. 为该弟子对应的 `NPCData` 发放“功勋点”。

### 2.2 阶级权限：官位阶梯 (Hierarchy)
官位决定了**“你有资格买什么”**，但不直接白送。
- **阶梯划分**：杂役 -> 外门弟子 -> 内门弟子 -> 执事 -> 长老 -> 掌门。
- **晋升算法**：`IF (当前修为 >= 职位硬性要求) AND (累计获得历史总功勋 >= 门槛)` -> 触发晋升。
- **闭环消费**：弟子拿到功勋后，同样前往【藏经阁】或【宝库】，花费功勋购买他这个官位能解锁的最强筑基丹。吞服突破后，修为提升，进而满足下一级官位的硬性要求。

### 2.3 宗门发展的生命周期阶段 (怎么分阶段)
宗门并不是一天建成的，它被严格划分为几个发展阈值（Phases）：
- **阶段一（草创期，Lv.1）**：百废待兴。大脑只发派最基础的伐木、采矿任务。只能解锁主殿和弟子茅草屋。NPC 行动范围极小。
- **阶段二（立足期，Lv.2）**：当宗门总功勋与财富达到阈值，触发“大建”事件。大脑开始派发猎杀高阶妖兽任务。建筑解锁炼丹房与炼器房，开启内门弟子考核。
- **阶段三（争霸期，Lv.3）**：宗门灵气需求飙升。此时大脑为了夺取周边更高阶的灵脉，会主动挑起针对其他邻近宗门的“边境战任务”，并派出执事与长老带队争夺。

## 3. 万物皆始于道具：开拓者与建宗令
系统废除了专职的“移民实体”，统一使用底层道具机制。

### 3.1 道具：【开宗立派阵盘】
- 无论是玩家还是野外 NPC，只要在背包中持有此道具并使用，即可触发建宗神迹。
- **AI 扩张口子**：当宗门发展到极盛，资源溢出时，大脑可能触发隐藏逻辑：赐予最强的一名巅峰长老【开宗阵盘】并将其逐出宗门，该长老将在地图远方建立“分宗”，实现游戏世界格局的自动演变。

## 4. 空间与视觉表现：模块化与延迟加载
保护显卡，所见即所得。

### 4.1 数据的后台推演
全图几十个宗门的招收弟子、发任务、抢地盘，全都在 `SocialManager` 和 `FactionManager` 的纯数据表中瞬间完成，没有任何 3D 渲染开销。

### 4.2 模块化预制体 (Socket Prefabs)
- 宗门是一组预制好的巨型模块集合（大殿、广场、炼丹房）。
- 它们通过预设的**连结点 (Sockets)** 相互连接，并根据当地山头的实际面积产生轻微的散布与自动修路。

### 4.3 视界坍缩 (Spatial Loading)
只有当玩家的坐标踏入该宗门所属的片区（Zone）时，引擎才会瞬间读取 `FactionManager` 的后台数据：
1. 实例化 3D 建筑预制体组合。
2. 将 `SocialManager` 里拥有该宗门 ID 的活人弟子 `NPCData` 具象化为 3D 实体模型并塞入场景中，执行他们当前正在进行的挂机行为。

## 5. 文明特性与外交矩阵 (Traits & Diplomacy)
- **发展特质 (Traits)**：类似于文明系列的国家特性，建宗时随机摇出。
  - *剑道魁首*：宗门弟子练剑速度 +30%，战力极强但财富积累极慢。
  - *万丹宝阁*：炼丹成功率提升，自动吸引散修前来高价购买丹药，极其富裕。
- **外交矩阵**：二维数组记录好感度。领土接壤会产生负面摩擦；贸易行为会增加好感。好感度决定了野外两派弟子相遇时是擦肩而过还是拔剑相向。
