# 00030entities: 游戏具象实体 (Entities)

## 设计愿景
包含了玩家在游戏中能看到、摸到、打到的所有“活物”和“死物”。这是 MVC 架构中的 View/Controller 层，负责将核心 `0000core` 算出的数据转化为华丽的 3D 视觉和动画表现。

## 核心子模块
- **`player/`**: 玩家主角的控制器、状态机、背包系统、镜头控制。
- **`npc/`**: 可交互的修仙者、门派弟子。受底层 `MacroSimulator` 驱动。
- **`monsters/`**: 妖兽与敌对生物。
- **`items/`**: 场景掉落物 (Loot Bags)。
- **`potion/`**: 丹药实体等。

## 架构规约
- 实体的状态变化应该调用 `0000core` 层的方法或响应其信号，尽量避免将深层次的结算逻辑（如伤害计算公式）写在表现层实体上。
- 模型文件 (`*.fbx`, `*.blend`) 如果是实体强绑定的，可放入各子模块下的 `models/` 目录中。
