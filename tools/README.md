# tools: 工程脚本与重构手术刀

## 设计愿景
本目录用于存放所有不参与 Godot 游戏运行时的“外部脚本”和“构建工具”。主要是 Python 脚本和 Godot EditorScript，用来自动化代码重构、场景节点批量修改或资源批量清洗。

## 核心子模块
- **`python_scripts/`**: 用于执行底层正则表达式替换、场景文件 `tscn` 暴力解析重构的 Python 独立脚本。
- **(根目录下的 `.gd` 工具)**: 大多数是需要在 Godot 编辑器上下文中运行的工具（如 `bake_animations_tool.gd`，`rig_character.gd`）。

## 架构规约
本目录内的代码永远不应该被游戏核心运行逻辑调用。它们只应该在开发阶段被开发者手动触发。
