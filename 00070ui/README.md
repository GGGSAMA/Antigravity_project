# 00070ui: 用户界面层 (User Interfaces)

## 设计愿景
管理所有的屏幕 2D 交互界面，包括 HUD、角色面板、炼丹面板、对话框等。

## 核心子模块
- **`dialogue/`**: 对话树渲染 UI。
- **`debug/`**: 开发者监控面板 (如 NPC 动态追踪、状态树监控)。
- *(其他功能 UI，如 `alchemy_panel` 等)*

## 架构规约
遵守 UI 纯显示原则（Dumb UI）。UI 脚本内绝对不应包含任何游戏核心结算逻辑。用户点击按钮时，只负责发送指令给对应的 Component 或 Core System，随后通过监听数据变更信号来刷新界面。
