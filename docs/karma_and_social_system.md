# 恩仇因果系统与核心循环 (Karma & Social Core Loop)

本设计文档奠定了游戏最核心的驱动力：**拒绝无脑刷怪，打造一个充满人情世故、资源极度匮乏、恩怨交织的真实修仙社会。**

## 核心设计哲学
修仙本质上是“逆天行事”，更是“与人斗”。
玩家的终极动力不是简单的“把攻击力升到 999”，而是活生生的情感诉求：**装逼打脸、报答当年一饭之恩、冲冠一怒为红颜、寻觅倾国倾城的道侣**。

### 0. 角色演绎代入法 (Character-Driven Empathy)
> **不要指望玩家自己去脑补，要让角色自己“演”出来！**
哪怕屏幕前的玩家是个毫无感情的“强度党（Min-Maxer）”，被抢了神器也觉得无所谓。但**游戏内的角色必须有所反应**！
参考《鬼谷八荒》的设计，当遭遇重挫、抢夺或羞辱时，角色自身必须通过头顶气泡、内心独白（日志）等方式，演绎出悲愤、隐忍、甚至立下血誓的桥段。
系统通过展示角色自身的“悲惨遭遇与主观愤怒”，来反向拉扯玩家的情绪，让玩家产生共情并代入其中，进而产生“帮我的小人报仇雪恨”的强烈游戏动力。

## 1. 核心循环：因果驱动的成长螺旋
游戏的底层驱动循环不应该是“打怪->掉装备->打更强的怪”，而应该是：
`争夺稀缺资源` -> `结缘/结仇` -> `遭遇打压/危机` -> `隐忍苦修提升` -> `报恩/复仇（装逼）` -> `接触更高阶层，引发新恩怨`

### 1.1 资源的高度稀缺性
正如“凡人流”小说（如韩立）的设定，修炼极度困难。
- **天然壁垒**：高灵气地块（如刚才实现的雪山灵脉）天然被大宗门和高阶妖兽霸占。
- **修为压制**：去新的地图或跨越高阶境界时，系统要有意“卡”玩家，甚至出现重伤跌落境界的剧情，强行制造困难，让每一次实力的恢复和提升都伴随巨大的成就感。

## 2. 两条截然不同的修仙道路

### A. 正道苦修流（韩立式）
- **特点**：资质平平，稳扎稳打。
- **玩法**：在夹缝中生存，低调采集灵草，结交善缘。偶尔捡漏，被大佬追杀时只能隐忍逃入穷乡僻壤（如毒瘴沼泽）苦修。
- **情感反馈**：大器晚成。百年之后神功大成，出山一巴掌拍死当年欺负自己的仇家，震撼整个修仙界。

### B. 邪修劫掠流（极道式）
- **特点**：走捷径，杀人夺宝。
- **玩法**：因为资质太差或者等不及，直接在野外截杀其他 NPC，抢夺资源。甚至布置魔阵，吸干一块领地的灵气（导致 `corruption_level` 上升）。
- **情感反馈**：爽快但极其危险。杀人越货会导致极高的“仇恨值（业力）”，满世界都会是追杀你的正派人士或寻仇的亲友团。为了活命，必须被迫以战养战，疯狂提升修为。

## 3. NPC 人际社交网络 (The Web of Karma)
NPC 不再是站桩发任务的工具人，而是有自己社交关系的实体：
- **亲友连带**：你杀了一个低阶弟子，过了几天他的师兄、道侣甚至护短的长老就会根据线索来追杀你。
- **恩果反哺**：你顺手救下或赠药给一个濒死的落魄修士，几十年后你被围攻时，他可能已经成为名震一方的大能，破空而来替你挡下致命一击。

> **总结**：修仙不仅是修境界，更是修因果。每一次资源的争夺，不仅是属性的加减，更是社交网络中“蝴蝶效应”的开始。
