# 核心视觉与操作路线图 (UI & Combat UX Roadmap)

这份文档旨在将我们通过多次探讨与截图分析，最终确立的 **“硬核地牢探索 (Dark and Darker) 风格 UI 与战斗系统”** 的最终需求彻底固化。这是接下来的所有前端代码开发的“宪法”。

## 1. 整体视觉哲学
**“画面视野至上，沉浸感极强，操作极度硬核且还原真实物理感。”**
所有的 UI 都不应该喧宾夺主，战斗 UI 必须极简，而打开（Tab）后台管理 UI 时必须足够复杂和细致。

## 2. 第一人称视角模型 (Viewmodel)
- **痛点**：当前武器和手掌的模型 Y 轴偏高，占据了太多屏幕中心视野。
- **目标**：全面下压左右手的 `Position3D`。在非攻击状态下，武器只能露出剑柄和一小截剑身，最大化玩家对环境的观察范围。

## 3. 沉浸式主界面 (Minimalist HUD)
参考图1与图3，摒弃漂浮在屏幕四周的 UI，采取“底部压扁”的策略。
- **正下方核心区**：红色的修长血条与蓝色的修长蓝条上下并排。上方紧贴着一排极小的技能/道具快捷槽。
- **左下角状态区**：放置玩家的写实头像框、职业/境界标识、当前的增益/减益 Buff 图标列。
- **右下角导航区**：放置正方形的带边框的微型小地图 (Minimap)。
- **正上方导航区**：极简的东南西北罗盘指示器。

## 4. 全屏硬核包裹与属性面板 (Hardcore Inventory & Stats)
参考图2，按下 `Tab` 键唤出的全屏面板，背景必须带有轻微的黑色半透明遮罩，透出背景 3D 环境。界面切分为极其严谨的三大块：
- **左侧 (详细属性清单)**：使用垂直滚动条，密密麻麻地列出玩家几十项底层属性（力量、敏捷、悟性、施法速度加成、护甲穿透等），鼠标悬浮需提供 Tooltip 解释。
- **中上方 (人形纸娃娃装备槽)**：提供一个清晰的人形轮廓，支持【头、胸、腿、脚、手套、披风、项链、戒指x2、左手武器、右手武器】的独立穿脱。
- **右下方 (网格化 Grid 背包)**：摒弃常规的列表式背包，采用真实的占格网格背包（例如长剑占 1x3，药水占 1x1），提供真正的“整理战利品”的乐趣。

## 5. Q/E 法术轮盘 (Radial Spell Wheel)
参考图3，针对法系技能，彻底抛弃数字键 `1234` 的僵硬施法，引入轮盘记忆机制。
- **触发**：按下 `Q` 键（左手记忆）或 `E` 键（右手记忆），瞬间呼出屏幕中央的【五芒星法术轮盘】。
- **操作锁定**：呼出轮盘的瞬间，鼠标被系统强制拉扯到屏幕绝对正中心。
- **象限选择**：玩家只需往对应法术的方向稍微滑动鼠标，系统计算偏移角度自动高亮选中该法术。松开按键后，该法术被“挂载”到对应的手上。

## 6. 双轨施法状态机 (Dual-Casting Engine)
参考图4，法术选好后，通过鼠标左右键实现**最极致的“搓招实感”**。
- **双施法条**：屏幕下方出现一左一右两个粉红色的吟唱进度条。
- **蓄力法术 (Hold to Charge)**：
  - 按住鼠标左键（或右键），对应的读条开始上涨。
  - 读条满后，法术在手中“成型”（例如左手冒出火焰特效，右手冒出寒气特效）。此时法术捏在手里不放，玩家可以自由走位瞄准。
  - 瞄准目标后，**松开按键 (Release)**，法球轰出。
- **连发法术 (Fast-Fire)**：
  - 针对低阶小法术，无需读条蓄力。
  - **按住不放 (Hold)**：就像开枪一样，法术“突突突”疯狂射出，频率极高但单发伤害极低。
- **施法中断**：在捏着法术或读条期间，随时按 `F` 键取消施法，避免浪费灵力。
