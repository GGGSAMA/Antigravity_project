# 核心开发标准与 AI 协作规范 (Coding Standards & AI Guidelines)

本文档记录了本项目在代码架构、工程实现以及 AI 辅助开发过程中的绝对铁律。
这些规则已被同步注入 AI 的全局记忆 (`.agents/AGENTS.md`) 中，作为后续开发的强约束。

## 1. 数据驱动架构 (Data-Driven Architecture)

**【绝对禁止硬编码魔法数字】**
任何涉及系统权重、概率、耗时、范围等策划向或调试向的参数，绝对不允许以魔法数字（Magic Numbers）的形式死板地写在代码逻辑内部。

**【检查器暴露原则】**
所有可配置参数，必须通过 `@export` (或 Resource 等机制) 暴露给 Godot 的属性检查器 (Inspector)。
确保策划和开发者可以直接在编辑器 UI 中选中节点并滑动滑块来调整这些数值，从而实现完全的“数据驱动设计”。

## 2. 脚本注释与规范 (GDScript Documentation)

**【文件级头部注释】**
以后所有新建或深度重构的 GDScript 文件，在脚本最上方的 `extends` 关键字下方，必须包含一个标准化的格式块注释 (`# ====` 分隔线包裹)。

**【必须包含的内容】**
头部注释必须清晰说明：
- 该脚本的**整体功能与架构定位**。
- 脚本内包含的**核心状态设定**。
- 具体的**核心接口描述**及其被谁调用、调用谁。

此规则确保每一份代码在未来回头翻阅时，只需看头部一眼便能完全掌控其生命周期。
