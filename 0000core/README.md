# 0000core: 核心引擎与全局模拟系统 (Core Simulation)

## 设计愿景
本模块是整个游戏的“大脑”。它负责所有独立于图形表现的深层逻辑运算，包括天道演化、宗门争霸、时间流逝以及全局事件驱动。
我们的目标是让核心层完全数据驱动且高度解耦，即：即便拔掉 3D 渲染画面，这套系统依然能在终端里作为“文字修仙游戏”独立运行。

## 核心子模块
- **`data/`**: 静态数据的底层基类库 (如 `base_data.gd`, `item_data.gd`)。
- **`simulation/`**: 
  - **`ai/`**: 宏观行为决策树 (Utility AI, Behavior Engine) 与特性过滤器。
  - **`events/`**: 宏观事件总线 (Event Bus)、奇遇管理器、叙事导演。
  - **`factions/`**: 宗门与势力引擎，包含资源生成、据点防卫、宗门人际关系图谱。
  - **`world/`**: 程序化大世界生成 (Procedural World Generation)。
  - **`time/`**: Chronos 绝对时间调度系统。
  - **`transactions/`**: 事务处理机，用于结算战斗、交易、修炼等脱机演算。
- **`ui/`**: 核心拖拽行为等抽象底层UI逻辑。

## 架构规约
1. **禁止依赖具体节点**: 本模块内部的代码绝不可以直接 `get_node()` 寻找外部的 `Player` 或具体的场景节点。
2. **纯数据驱动**: 对外只抛出 Signal，不直接操纵外部实体的动画或视觉特效。
